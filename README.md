## 我的开发方式

- 先保证系统能够运行和复现，再讨论模型效果。
- 关注知识来源、失败回退和已知限制。
- 为核心项目补充 README、测试和 CI。
- 使用生成式 AI 辅助开发，并明确区分 AI 生成、人工取舍与验证结果。
